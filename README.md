# HR-Analytics-Dashboard-Using-Tableau

A comprehensive **Tableau HR Analytics Dashboard** developed to transform employee data into meaningful workforce insights. The dashboard provides an overview of **employee demographics, gender distribution, departments, job roles, education fields, marital status, average age, monthly income, and work experience**.

It enables users to explore workforce patterns across different departments and job roles, compare employee characteristics, and understand key HR metrics. The interactive visualizations make complex employee data easier to analyze and support **data-driven workforce planning and HR decision-making**.

**Tools Used:** Tableau, Data Visualization, HR Analytics, Data Analysis.
